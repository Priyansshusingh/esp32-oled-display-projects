# ESP32 OLED Display Projects

A collection of small embedded projects built using ESP32 and OLED displays.

## 🛠️ Hardware

- ESP32
- OLED Display (128×32 / 128×64)
- I2C

## 💻 Technologies

- C / C++
- Arduino IDE
- I2C
- Embedded Systems

## 📌 Projects

- OLED text display
- Animated OLED interface
- Two-display name display
- Basic OLED user interface

## 🚀 Future Improvements

- More OLED animations
- Sensor data visualization
- Interactive user interfaces
